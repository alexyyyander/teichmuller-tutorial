关于项目

本项目是 Teichmüller 理论的综合教程与形式化验证仓库，目标是恢复 1944 年提出的统一路线， 让复几何、拓扑与算术在同一个框架下重新汇合。支持多 agent 协作探索，通过严格审查机制保证质量。
