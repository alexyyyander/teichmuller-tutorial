作用、映射与拟共形结构：三个可计算模型

本页不设置动画，而是给出三个固定的、可以逐行手算核验的代表模型：先明确对象、定义域与映射，再计算轨道、复合差或微分不变量， 最后说明这个具体例子与一般理论的边界。

模型数据 写出 G↷X、f:X→Y 或 f(z)=az+b z̄，固定具体对象与假设。
可验证量 在一个具体输入上计算 Orb、Stab、复合差、Jacobian、K。
结论边界 区分算例中的等式、一般命题，以及尚未涉及的全局定理。

1. 有限群作用：轨道—稳定子分解

取最小的非平凡旋转例子：四阶循环群作用在复平面上，选定点为 x=1。

模型 A · 有限群
作用对象G=C4={e,r,r²,r³}，r⁴=e
作用空间X=ℂ，r·z=iz
轨道OrbG(x)={g·x∣g∈G}
稳定子StabG(x)={g∈G∣g·x=x}

红点为 x=1，蓝点为 {1,i,−1,−i}；中心的灰点同时显示固定点 0 的另一种轨道类型。

具体算例n=4，x=1
r·1=i，r²·1=−1，r³·1=−i

|C4| = |OrbG(1)| · |StabG(1)| = 4·1

|G|4
|OrbG(1)|4
|StabG(1)|1
乘积检查4 = 4 × 1
定义轨道是评价映射 G→X，g↦g·x 的像；稳定子是该映射在 x 处取值不变的群元素集合。
命题当 G 有限时，G/StabG(x)→OrbG(x)，g Stab↦g·x 是良定义双射，因此得到上面的乘法公式。
证明要点g1·x=g2·x 当且仅当 g2−1g1∈StabG(x)；所以两个群元素给出同一点，恰好对应同一个左陪集。
范围：这是一个 C4 算例；它说明定理如何计算，不代表任意群作用都只有四个轨道点。

2. 复映射：复合顺序与不交换性

固定一个输入 z=1+i，取四分之一转与单位平移，逐步写出两条复合路径。

模型 B · 全纯自同构
定义域/陪域X=Y=ℂ
旋转f(z)=iz，即 θ=π/2
平移g(z)=z+1
输入z=1+i，不改变参数

两条箭头链分别展示 z→f(z)→g(f(z)) 与 z→g(z)→f(g(z))，每一步都可直接核算。

具体算例θ=π/2，z=1+i
f(z)=−1+i，g(z)=2+i

g(f(z))=i，f(g(z))=−1+2i
f(g(z))−g(f(z))=−1+i，模为 √2

g(f(z))i
f(g(z))−1+2i
差向量模√2
复合关系不交换
计算fθ(g(z))=eiθ(z+1)，而 g(fθ(z))=eiθz+1；差值与输入 z 无关。
命题本算例中 g∘f≠f∘g；这正是“复合顺序属于结构数据”的具体证据。
计算f(g(1+i))=i(2+i)=−1+2i，而 g(f(1+i))=g(−1+i)=i，两者不同。
范围：这两个映射都是 ℂ 的全纯自同构；图形只验证代数关系，不替代全纯性和自同构的正式证明。

3. 拟共形变形：Beltrami 系数的实一维截面

固定 μ=1/2，把单位圆和方格送入一个可直接写出矩阵的仿射拟共形映射。

模型 C · 仿射拟共形
模型f(z)=z+½z̄，即 μ=½
Wirtinger 导数fz=1，fz̄=μ
JacobianJf=|fz|²−|fz̄|²=1−k²>0
畸变K=(1+½)/(1−½)=3，是主伸缩比

灰色虚线是原坐标；蓝、红线是 Df=diag(3/2,1/2) 作用后的像。单位圆变为半轴 3/2 与 1/2 的椭圆。

具体算例μ=k=1/2
f(x+iy)=3x/2+i·y/2

Df=diag(3/2,1/2)，Jf=3/4，K=3
dmodel=½ log 3

主伸缩 λ11.35
主伸缩 λ20.65
Jacobian Jf0.75
畸变常数 K3
模型距离 dmodel½ log 3
定义在一般情形中，μ=fz̄/fz（几乎处处定义）控制共形偏离；本页只取常数且为实数的 μ=k。
命题本算例中 Jf=3/4>0，因此保持定向；两个主伸缩因子的比为 K=3。
计算z=x+iy 时，z+½z̄=3x/2+i·y/2，所以 Df=diag(3/2,1/2)。
范围：这是一个常系数、实 μ 的仿射算例；dmodel 不等同于完整 Teichmüller 空间的全局距离，也不证明极值性。

三个模型依次对应代数中的商集、复分析中的自同构复合，以及拟共形理论中的局部微分数据。 它们展示的是“可计算的截面”：群作用、全纯映射和 Beltrami 系数的正式定义仍需在正文中学习； 更不能由这些有限维图像直接推出模空间、解析族或 Teichmüller 极值定理。
